# Contributing

Keep changes small and explain the problem they solve. For setup and checks, see [development](docs/development.md).

For a bug report, include Windows, app and yt-dlp versions, the chosen quality, and a redacted error. Share a public test link only if you are allowed to share it. Do not attach cookies, private URLs or downloaded copyrighted files.

For code changes, add a meaningful test for behavior changes and run the test suite and Ruff. Keep UI work on the main thread. Keep the interface and wording simple. Avoid unrelated dependencies and large refactors.

Contributions are submitted under this project's MIT license. Preserve existing third-party notices. By contributing, you confirm that you have the right to contribute the material.
