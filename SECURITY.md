# Security

Only the latest release is maintained. Support is best effort, with no promised response time.

Do not put secrets or exploit details in a public issue. After publication, use the repository's **Security > Report a vulnerability** option if it is enabled. If it is unavailable, open a general issue asking for a private contact without including the sensitive details. Private vulnerability reporting must be enabled by the repository owner before release.

Use current versions of yt-dlp, FFmpeg and Deno from trusted sources. Do not run unknown binaries or import someone else's cookies. The app runs downloaded content through external tools; treat untrusted media with care.

The app does not provide a hosted download endpoint. If you add one, you need separate protections for URLs, network access, users, storage and resource limits.
